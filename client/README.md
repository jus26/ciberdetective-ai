# CiberDetective AI — Cliente (Paso 2)

Directorio reservado para la aplicación frontend en React + TypeScript + Tailwind CSS.
La estructura planificada para el cliente incluye:
- `src/components/` — Componentes SOC (Visor de evidencias, Panel IA, Foro de debate, Ranking, Admin)
- `src/context/` — Contexto de autenticación JWT y estado del detective
- `src/pages/` — Vistas principales (Inicio, Misiones, Detalle de Misión, Perfil, Clasificación, Administración)
- `src/services/` — Cliente HTTP hacia `/api/*`
- `src/types/` — Interfaces compartidas
